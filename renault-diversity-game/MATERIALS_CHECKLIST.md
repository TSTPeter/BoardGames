# Materials Checklist - Renault D&I Game

Use this checklist to ensure you have everything needed to run the game.

## Essential Materials (Per Table)

### Playing Components
- [ ] **1 standard 52-card deck** (or custom Renault deck)
  - Hearts (13 cards: 1-13)
  - Diamonds (13 cards: 1-13)
  - Clubs (13 cards: 1-13)
  - Spades (13 cards: 1-13)

- [ ] **Challenge Deck** (20 cards)
  - Challenges 1-10 (Beginner)
  - Challenges 11-20 (Advanced)
  - Printed and ordered OR shuffled based on difficulty chosen

- [ ] **Gold Deck** (10 cards)
  - Gold Cards 1-10
  - Printed and stacked in order

- [ ] **Player Ability Cards** (6 cards)
  - The Connector
  - The Observer
  - The Advocate
  - The Innovator
  - The Mentor
  - The Adapter
  - (Add The Coordinator and The Champion for 7-8 players)

### Supporting Materials
- [ ] **Score tracking sheet** or tokens
- [ ] **Suit reference card** (Hearts=Hiring, Diamonds=Development, Clubs=Culture, Spades=Voice)
- [ ] **Playing surface** (table with adequate space)
- [ ] **Rules summary card** (optional but helpful)

## Facilitator Materials

### Session Materials
- [ ] **Facilitator Guide** (printed or accessible)
- [ ] **Session agenda** (printed)
- [ ] **Timer** (phone or dedicated timer)
- [ ] **Name tags or tent cards** (if participants don't know each other)

### Discussion Materials
- [ ] **Flip chart and markers** OR whiteboard
- [ ] **Post-it notes** (for capturing insights)
- [ ] **Personal reflection worksheets** (optional, template in Facilitator Guide)
- [ ] **Commitment cards** (for participants to write personal commitments)

### Handouts
- [ ] **Suit reference sheet** (one per participant)
- [ ] **Quick rules summary** (one per participant)
- [ ] **Resource list** (for continued learning)
- [ ] **Contact information** (for follow-up questions)

## Room Setup

### Physical Space
- [ ] **Round or square table(s)** for 4-6 players each
- [ ] **Chairs** for all participants
- [ ] **Adequate lighting** (players need to see cards clearly)
- [ ] **Minimal noise/distractions**

### For Multiple Tables
- [ ] **Tables spaced apart** for separate conversations
- [ ] **Central area** for facilitator instructions
- [ ] **Signal for attention** (bell, hand signal, etc.)
- [ ] **Clear sightlines** (facilitator can see all tables)

### Audio/Visual (Optional)
- [ ] **Projector or screen** (for showing rules, discussion questions)
- [ ] **Speakers** (if using audio)
- [ ] **Presentation slides** (optional - game works without)

## Pre-Session Checklist

### One Week Before
- [ ] **Confirm participant count**
- [ ] **Print all card decks** (based on participant count)
- [ ] **Reserve room**
- [ ] **Send pre-session email** with logistics
- [ ] **Prepare facilitator materials**
- [ ] **Review all content** (rules, challenges, Gold Cards)

### One Day Before
- [ ] **Confirm room setup**
- [ ] **Print any final materials**
- [ ] **Pack all materials** in organized way
- [ ] **Test any A/V equipment**
- [ ] **Prepare opening remarks**
- [ ] **Review participant names/backgrounds**

### Day Of (Setup Time)
- [ ] **Arrive early** (30-60 minutes before start)
- [ ] **Set up room** (tables, chairs)
- [ ] **Place materials at each table**
- [ ] **Test A/V** if using
- [ ] **Prepare flip chart** with welcome message
- [ ] **Set up check-in area** if using
- [ ] **Final mental preparation** and intention setting

## Materials by Participant Count

### 3 Players (1 Table)
- 1 playing card deck
- 1 Challenge Deck
- 1 Gold Deck
- 3 Player Ability cards (use Abilities 1-3)
- 1 score tracker

### 4 Players (1 Table)
- 1 playing card deck
- 1 Challenge Deck
- 1 Gold Deck
- 4 Player Ability cards (use Abilities 1-4)
- 1 score tracker

### 5 Players (1 Table)
- 1 playing card deck
- 1 Challenge Deck
- 1 Gold Deck
- 5 Player Ability cards (use Abilities 1-5)
- 1 score tracker

### 6 Players (1 Table)
- 1 playing card deck
- 1 Challenge Deck
- 1 Gold Deck
- 6 Player Ability cards (use Abilities 1-6)
- 1 score tracker

### 12 Players (2 Tables)
- 2 playing card decks
- 2 Challenge Decks (or 1 shared)
- 2 Gold Decks (or 1 shared)
- 12 Player Ability cards (6 per table)
- 2 score trackers

### 20 Players (4 Tables)
Multiply single-table materials by 4.

### Large Groups (30+ Players)
- Plan for 1 set of materials per 5-6 participants
- Consider hiring additional facilitators (1 per 12-18 participants)
- Extended room with space for multiple table clusters

## Sourcing Materials

### Playing Cards
- **Standard decks:** Any retail store, Amazon, bulk suppliers
- **Custom decks:** PrintNinja, MakePlayingCards, DriveThruCards
- **Quantity needed:** 1 per 6 players

### Printed Cards (Challenge, Gold, Ability)
- **DIY:** Print on cardstock, cut, optional lamination
- **Print shop:** Local printer, 300gsm cardstock, optional lamination
- **Professional:** Game card printing services
- **Quantity needed:** 1 set per table (can be shared across tables if needed)

### Card Sleeves (Optional)
- Protect cards from wear
- Standard poker size: 63.5mm × 88mm
- Buy from game stores or Amazon
- ~€5-10 per set

### Storage
- Card boxes (per table): €5-10
- Larger storage bin (all materials): €15-30
- Professional carry case: €50-100

## Accessibility Considerations

### Visual Accessibility
- [ ] **Large print option** for rules and cards available
- [ ] **High contrast** card designs
- [ ] **Adequate lighting** in room
- [ ] **Consider Braille** labels for blind participants (advanced)

### Physical Accessibility
- [ ] **Accessible table height** for wheelchair users
- [ ] **Card holders** available for those with limited hand mobility
- [ ] **Assistance available** for card manipulation if needed

### Language Accessibility
- [ ] **Materials in required languages** (English, French, other Renault languages)
- [ ] **Translation support** if participants have varied language fluency
- [ ] **Clear, simple language** in instructions

## Quality Check Before Session

Final check 1 hour before:
- [ ] **Card decks complete** (count all cards)
- [ ] **Cards shuffled** where appropriate
- [ ] **Materials at each table** in organized manner
- [ ] **Backup supplies** (extra pens, paper, etc.)
- [ ] **Facilitator guide** accessible and bookmarked
- [ ] **Water/refreshments** available (optional)

## Post-Session Materials

To send participants afterward:
- [ ] **Summary of session insights**
- [ ] **List of commitments made**
- [ ] **Resource links** for continued learning
- [ ] **Contact information** for follow-up
- [ ] **Survey link** (if using)

## Reusability & Care

### After Each Session
- Check all cards are present (full deck)
- Return cards to proper decks
- Note any damaged cards for replacement
- Store in dry, safe location

### Maintenance
- Replace worn cards as needed
- Keep backup printed sets
- Update Challenge/Gold cards if content evolves
- Refresh facilitator guide with learnings

### Expected Lifespan
- **Playing cards:** 20-50 sessions (with care)
- **Printed cards:** 30-100 sessions (if laminated)
- **Facilitator guide:** Indefinite (update as needed)

## Emergency Backup Kit

Keep on hand in case of issues:
- [ ] **Blank cards** (for replacing damaged ones)
- [ ] **Extra pens/markers**
- [ ] **Paper** for notes
- [ ] **Tape/glue** for repairs
- [ ] **Rules reference** (quick lookup)
- [ ] **Facilitator contact info** for questions
