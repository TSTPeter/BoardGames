# BoardGames
A collection of exemplar board games that we could play to help enrich diversity understanding

## Games in This Collection

### Renault Diversity & Inclusion: The Cooperative Challenge

A cooperative trick-taking card game designed to build awareness of workplace diversity and inclusion through experiential learning.

**Key Features:**
- Cooperative gameplay (team wins or loses together)
- Asymmetrical player abilities (highlighting diverse strengths)
- Rules-light mechanics (focus on concepts, not complexity)
- Challenge-based progression (20 scenarios based on real D&I situations)
- Integrated discussion (Gold Cards connect gameplay to research)

**Learning Outcomes:**
- Build D&I awareness
- Identify inclusive vs. non-inclusive behaviors
- Apply concepts to individual business contexts
- Commit to personal behavioral changes

**Duration:** 90-120 minutes (including facilitated discussion)
**Players:** 3-6 per table (scalable to large groups)

## About This Repository

This repository contains board games designed specifically for diversity and inclusion education and team development. Each game uses experiential learning to help participants:

- Experience D&I concepts viscerally, not just intellectually
- Engage with challenging topics in a psychologically safe way
- Practice inclusive behaviors in a low-stakes environment
- Connect abstract concepts to real workplace situations
- Commit to concrete action and behavioral change

## Usage

These games are designed for:
- Team development sessions
- D&I training programs
- Leadership development
- Onboarding and integration
- Ongoing team health maintenance
